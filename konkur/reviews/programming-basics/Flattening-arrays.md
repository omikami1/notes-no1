# سطحی‌سازی (Flattening) آرایه n‑بعدی — سطری و ستونی

فرض کن آرایه‌ای داریم با ابعاد:
```
A[D₁][D₂][D₃] ... [Dₙ]
```

اندیس‌ها: `(i₁, i₂, i₃, …, iₙ)` که هر کدام در بازه `0 ≤ i_k < D_k` هستند.

می‌خواهیم این آرایه را در یک آرایه تک‌بعدی `B[]` با اندازه `N = D₁ × D₂ × … × Dₙ` ذخیره کنیم.
**مهم :** نرمال سازی اندیس ها فراموش نشه: اگر اندیس از x شروع شده باشه باید i-x رو حساب کنیم

---

## ۱) فرمول سطری (Row-Major)

### قاعده شهودی
**آخرین اندیس (`iₙ`) سریع‌ترین تغییر می‌کند**، بعد `iₙ₋₁`، و به همین ترتیب تا `i₁`.

مثل این‌که یک شمارنده چند رقمی داریم و رقم‌های سمت راست زودتر می‌چرخند.

### فرمول عمومی
```
index = i₁·(D₂·D₃·…·Dₙ)
      + i₂·(D₃·…·Dₙ)
      + i₃·(D₄·…·Dₙ)
      + …
      + iₙ₋₁·(Dₙ)
      + iₙ
```

### فرمول بازگشتی (راحت‌تر برای کد)
```
index = 0
for k = 1 to n:
    index = index * D_k + i_k
```
یا معادلش:
```
index = ((((i₁)·D₂ + i₂)·D₃ + i₃)·D₄ + … )·Dₙ + iₙ
```

### مثال `A[3][2][2]` — سطری
- `D₁=3, D₂=2, D₃=2`
- `index = ((i₁)·2 + i₂)·2 + i₃`
- برای `(1,0,1)`: `((1)·2 + 0)·2 + 1 = 4 + 1 = 5` ✅ (همان قبلی)

## ۲) فرمول ستونی (Column-Major)

### قاعده شهودی
**اولین اندیس (`i₁`) سریع‌ترین تغییر می‌کند**، بعد `i₂`، تا `iₙ`.

مثل شمارنده‌ای که رقم‌های سمت چپ زودتر می‌چرخند.

### فرمول عمومی
```
index = i₁
      + i₂·(D₁)
      + i₃·(D₁·D₂)
      + i₄·(D₁·D₂·D₃)
      + …
      + iₙ·(D₁·D₂·…·Dₙ₋₁)
```

### فرمول بازگشتی
```
index = 0
for k = n down to 1:
    index = index * D_k + i_k
```
یا معادل باز شده:
```
index = ((((iₙ)·Dₙ₋₁ + iₙ₋₁)·Dₙ₋₂ + … )·D₁ + i₁)
```![[row-major-3D.png]]

### مثال `A[3][2][2]` — ستونی
- `D₁=3, D₂=2, D₃=2`
- فرمول: `i₁ + i₂·3 + i₃·(3·2) = i₁ + 3·i₂ + 6·i₃`
- برای `(1,0,1)`: `1 + 0 + 6 = 7` ✅
