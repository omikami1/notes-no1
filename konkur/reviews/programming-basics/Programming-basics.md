# فصل ۱: مفاهیم اولیه

## ۱.۱ تاریخچه و زبان‌ها
- **C** توسط Dennis Ritchie در ۱۹۷۲ در Bell Labs برای نوشتن UNIX طراحی شد.
- **C++** توسط Bjarne Stroustrup در ۱۹۷۹ توسعه یافت (ابتدا "C with Classes").
- C یک زبان **سطح میانی** (میان سطح بالا و اسمبلی) است — قابل حمل + دسترسی به سخت‌افزار.

## ۱.۲ مراحل ساخت برنامه
```
سورس (.c) → پیش‌پردازش → کامپایل → اسمبلی → لینک → فایل اجرایی
              ↓            ↓          ↓        ↓
           #include     کد اسمبلی   فایل .o   کتابخانه‌ها
```

| مرحله | ابزار | خروجی |
|-------|-------|-------|
| پیش‌پردازش | cpp | کد گسترش‌یافته |
| کامپایل | gcc -S | اسمبلی |
| اسمبلی | as | فایل شیء (.o) |
| لینک | ld | اجرایی |

**نکته کنکوری:** خطاهای **زمان کامپایل** (نحوی) از **زمان لینک** (توابع تعریف‌نشده) و **زمان اجرا** (منطقی) جداست.

## ۲.۲ مکمل دو (Two's Complement) — **کلیدی!**

برای عدد منفی: معکوس بیت‌ها + ۱

```
+5  = 0000 0101
-5  = 1111 1010 + 1 = 1111 1011
```

**محدوده n بیتی:**
- علامت‌دار: `-2^(n-1)` تا `2^(n-1) - 1`
- بدون علامت: `0` تا `2^n - 1`

**نکته کنکوری:** در مکمل دو، `~x = -x - 1` (چرا؟ چون `x + ~x = -1`)

## ۲.۳ ممیز شناور (IEEE 754)

| نوع | علامت | توان | مانتیس | کل |
|-----|-------|------|--------|-----|
| float | 1 | 8 | 23 | 32 |
| double | 1 | 11 | 52 | 64 |

فرمول: `(-1)^S × 1.M × 2^(E-bias)` که bias = 127 (float)

**نکته مهم:** اعداد اعشاری دقیقاً ذخیره نمی‌شوند → هرگز با `==` مقایسه نکنید!

فرمول جالب : در n بیت باینری چند رقم میشه نگه داشت: n * lgo10(2) (مثلا دقت در float: 23 × 0.30103 ≈ 6.92 → 7  ) پس دقت اعشار اش تقریبا ۷ رقم هست اش

# فصل ۹: آرایه‌ها

## ۹.۱ آرایه یک‌بعدی
```c
int arr[10];              // تعریف
int arr[5] = {1,2,3,4,5}; // مقداردهی
int arr[] = {1,2,3};      // اندازه خودکار
```

**نکته:** اندیس از 0 تا n-1. بدون بررسی محدوده (خطر!)

## ۹.۲ جست‌وجوی دودویی (Binary Search)
```c
int binarySearch(int arr[], int n, int target) {
    int left = 0, right = n - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;  // جلوگیری از Overflow
        if (arr[mid] == target) return mid;
        if (arr[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}
```
- **پیش‌نیاز:** آرایه مرتب
- **پیچیدگی:** O(log n)

## ۹.۳ مرتب‌سازی

| الگوریتم | بهترین | متوسط | بدترین | پایدار |
|----------|--------|--------|---------|--------|
| Bubble | O(n) | O(n²) | O(n²) | ✅ |
| Selection | O(n²) | O(n²) | O(n²) | ❌ |
| Insertion | O(n) | O(n²) | O(n²) | ✅ |
| Merge | O(n log n) | O(n log n) | O(n log n) | ✅ |
| Quick | O(n log n) | O(n log n) | O(n²) | ❌ |

## ۹.۴ آرایه دوبعدی

```
آدرس arr[i][j] = base + (i * COLS + j) * sizeof(type)
```

**نکته:** در حافظه به صورت **Row-Major** ذخیره می‌شود.

# فصل ۱۰: اشاره‌گرها — **مهم‌ترین فصل!**

## ۱۰.۱ عملگرها
```c
int x = 10;
int *p = &x;   // p آدرس x را دارد
*p = 20;       // تغییر مقدار x
```

## ۱۰.۲ اشاره‌گر و آرایه

```c
int arr[5];
// این‌ها معادل‌اند:
arr[i]  ≡  *(arr + i)  ≡  *(i + arr)  ≡  i[arr]
&arr[i] ≡  arr + i
```

**نکته طلایی:** نام آرایه = اشاره‌گر به اولین عنصر (اما `sizeof` و `&` فرق دارند).

## ۱۰.۳ محاسبات اشاره‌گری

```c
int *p;
p + 1   // آدرس + sizeof(int) بایت جلو
p - 1   // آدرس - sizeof(int) بایت عقب
p1 - p2 // تعداد عناصر بین دو اشاره‌گر
```

## ۱۰.۴ const و اشاره‌گر

| تعریف | معنی |
|-------|------|
| `const int *p` | مقدار قابل تغییر نیست (*p = ... ممنوع) |
| `int * const p` | خود اشاره‌گر ثابت (p++ ممنوع) |
| `const int * const p` | هر دو ثابت |

## ۱۰.۵ آرایه اشاره‌گرها vs اشاره‌گر به آرایه

```c

## ۱۲.۴ عملگرهای بیتی — **مهم!**

| عملگر | کار | مثال |
|-------|-----|------|
| `&` | AND | `1010 & 1100 = 1000` |
| `\|` | OR | `1010 \| 1100 = 1110` |
| `^` | XOR | `1010 ^ 1100 = 0110` |
| `~` | NOT | `~1010 = 0101` |

```

**نکته:** `x & (x-1)` کم‌ارزش‌ترین بیت ۱ را پاک می‌کند.

## ۱۴.۲ سطوح دسترسی

| سطح | داخل کلاس | خارج | مشتق |
|-----|-----------|------|------|

| private | ✅ | ❌ | ❌ |

**تفاوت struct/class:** پیش‌فرض struct=public، class=private.

## ۱۴.۳ سازنده‌ها

```cpp
// پیش‌فرض
Point() : x(0), y(0) {}

// پارامتری
Point(int x, int y) : x(x), y(y) {}

// کپی
Point(const Point &other) : x(other.x), y(other.y) {}

// با مقدار پیش‌فرض
Point(int x = 0, int y = 0) : x(x), y(y) {}
```

**نکته:** Initializer List برای `const` و reference **اجباری** است.

# فصل اضافه ۲: نکات مهم کنکوری

## اشتباهات رایج

1. **`sizeof` روی آرایه در تابع** = اندازه اشاره‌گر (نه آرایه!)
2. **مقایسه float با `==`** — خطرناک
3. **`strncpy` بدون `\0`** — اگر n کوچک باشد
4. **`x & (x-1)`** — پاک کردن کم‌ارزش‌ترین بیت ۱
5. **`a[i] = i++`** — Undefined Behavior
6. **`char *s = "hello"; s[0]='H'`** — خطا (رشته ثابت)
7. **`sizeof(struct)`** — شامل padding
8. **`>>` برای اعداد منفی** — رفتار پیاده‌سازی‌وابسته

## نکات ریاضی

| فرمول | کاربرد |
|-------|--------|
| `~x = -x - 1` | مکمل دو |
| `x & (x-1)` | حذف کم‌ارزش‌ترین 1 |
| `x \| (1<<n)` | روشن کردن بیت |
| `x & ~(1<<n)` | خاموش کردن بیت |
| `(x >> n) & 1` | تست بیت n |
| `mid = l + (r-l)/2` | جلوگیری از Overflow |
| `n & (n-1) == 0` | توان دو؟ |
