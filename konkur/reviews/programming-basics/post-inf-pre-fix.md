عالی! دقیقاً همون‌طور که گفتی، برای دو تبدیل آخر (`Pre ↔ Post`) بهتره **Infix رو واسط** کنیم، چون مستقیمش پیچیده و مستعد خطاست. اینجا هر ۶ حالت رو در یک قالب مرتب و تستی می‌گم که راحت ذخیره کنی.

---

# قالب کلی: ۶ تبدیل عبارات

## قانون طلایی برای حفظ کردن جهت پیمایش

| تبدیل | جهت پیمایش | Stack یا واسط |
|--------|------------|----------------|
| Infix → Postfix | چپ به راست | Stack عملگر |
| Infix → Prefix | **راست به چپ** | Stack عملگر |
| Postfix → Infix | چپ به راست | Stack عملوند |
| Prefix → Infix | راست به چپ | Stack عملوند |
| Postfix → Prefix | — | از Infix واسط |
| Prefix → Postfix | — | از Infix واسط |

**ترفند:**  
- هر جا **Infix مقصد** است → Stack عملوند  
- هر جا **Infix مبدأ** است → Stack عملگر  
- Prefix همیشه **برعکس** (راست به چپ) خونده می‌شه

---

## ۱) Infix → Postfix

**پیمایش چپ به راست** + Stack برای عملگرها

قانون:
- عملوند → مستقیم به خروجی
- عملگر → تا وقتی اولویت بالاتر یا مساوی روی Stack هست، pop کن به خروجی، بعد push کن
- `(` → push
- `)` → تا `(` pop کن به خروجی
- آخرش هرچی موند pop کن

**اولویت:** `^` > `* /` > `+ -`

### مثال: `A+B*C`
خروجی: `ABC*+`

---

## ۲) Infix → Prefix

**پیمایش راست به چپ** + Stack برای عملگرها

قانون:
- عملوند → مستقیم به خروجی
- عملگر → مثل بالا ولی توجه کن `(` و `)` جاشون عوض می‌شه (چون برعکس می‌خونیم)
- آخرش خروجی رو **reverse** کن

### مثال: `A+B*C`
بعد از پیمایش راست به چپ → `+A*BC` → reverse → `+A*BC`  
**جواب: `+A*BC`**

---

## ۳) Postfix → Infix

**پیمایش چپ به راست** + Stack برای عملوندها

قانون:
- عملوند → push
- عملگر → pop دو تا:
  - اولی = **راست**
  - دومی = **چپ**
  - بساز `(چپ عملگر راست)` و push کن

### مثال: `ABC*+`
**جواب: `(A+(B*C))`**

---

## ۴) Prefix → Infix

**پیمایش راست به چپ** + Stack برای عملوندها

قانون:
- عملوند → push
- عملگر → pop دو تا:
  - اولی = **چپ**
  - دومی = **راست**
  - بساز `(چپ عملگر راست)` و push کن

### مثال: `+A*BC`
**جواب: `(A+(B*C))`**

---

## ۵) Postfix → Prefix

**روش واسط (Infix):**
1. Postfix → Infix
2. Infix → Prefix

### مثال: `ABC*+`
- Postfix → Infix: `(A+(B*C))`
- Infix → Prefix: `+A*BC`

**جواب: `+A*BC`**

> روش مستقیم هم هست (پیمایش چپ به راست + Stack، ساخت رشته با عملگر در ابتدا) ولی چون خطاپذیره، واسط امن‌تره.

---

## ۶) Prefix → Postfix

**روش واسط (Infix):**
1. Prefix → Infix
2. Infix → Postfix

### مثال: `+A*BC`
- Prefix → Infix: `(A+(B*C))`
- Infix → Postfix: `ABC*+`

**جواب: `ABC*+`**

---

# جدول جمع‌بندی نهایی (برای ذخیره)

| # | تبدیل | روش | نکته کلیدی |
|---|--------|-----|-------------|
| 1 | Infix → Postfix | Stack عملگر، چپ به راست | اولویت + پرانتز |
| 2 | Infix → Prefix | Stack عملگر، راست به چپ + reverse | پرانتزها برعکس |
| 3 | Postfix → Infix | Stack عملوند، چپ به راست | اولی=راست، دومی=چپ |
| 4 | Prefix → Infix | Stack عملوند، راست به چپ | اولی=چپ، دومی=راست |
| 5 | Postfix → Prefix | Infix واسط | ۱ بعد ۲ |
| 6 | Prefix → Postfix | Infix واسط | ۴ بعد ۱ |

---

# نکات تستی نهایی ⚡

1. **تعداد عملوند = تعداد عملگر + ۱**
2. Prefix همیشه **برعکس** خونده می‌شه (راست به چپ)
3. در Postfix→Infix: **اولی=راست، دومی=چپ**
4. در Prefix→Infix: **اولی=چپ، دومی=راست**
5. برای `Pre ↔ Post` همیشه **Infix واسط** بذار → امن‌ترین راه
6. بعد از هر تبدیل، برگردون به مبدأ تا مطمئن شی درسته
